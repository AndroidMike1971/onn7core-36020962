============================================================
RECOMMENDED ROOT METHOD
============================================================

The recommended method is to patch the stock init_boot image
yourself using Magisk rather than blindly flashing a pre-patched
image.

1. Unlock the bootloader.

WARNING:
THIS ERASES USER DATA.

2. Install Magisk on the tablet.

3. Copy the stock init_boot image to the tablet.

Example:

adb push init_boot_b.img /sdcard/Download/init_boot_b.img

4. Open Magisk.

Select:

Install
Select and Patch a File

Select:

init_boot_b.img

5. Allow Magisk to finish patching the image.

The resulting file will normally appear in:

/sdcard/Download/

with a filename similar to:

magisk_patched-XXXXX.img

6. Copy the patched image back to the computer.

Example:

adb pull /sdcard/Download/magisk_patched-XXXXX.img


============================================================
FLASHING
============================================================

Reboot to the bootloader:

adb reboot bootloader

Confirm Fastboot communication:

fastboot devices

Confirm the bootloader is unlocked:

fastboot getvar unlocked

Confirm the active slot:

fastboot getvar current-slot


IMPORTANT:

The device used to develop and test this package was operating
from SLOT B.

DO NOT blindly assume your device is currently using slot B.


For a verified SLOT B device, the tested flash command is:

fastboot flash init_boot_b magisk_patched_init_boot_b.img

After a successful flash:

fastboot reboot


============================================================
FIRST BOOT
============================================================

Allow Android to boot normally.

Open Magisk.

Magisk may request additional setup and another reboot.

Allow it to complete the installation.

After the reboot, Magisk should report itself as installed.


============================================================
VERIFY ROOT
============================================================

Connect through ADB:

adb shell

Request root:

su

Magisk should display a Superuser permission request on the tablet.

Grant permission.

Then run:

id

Successful root should return uid=0(root).

The development device returned:

uid=0(root) gid=0(root) groups=0(root) context=u:r:magisk:s0


============================================================
RESTORING STOCK INIT_BOOT
============================================================

The original stock init_boot image is included specifically so
the modification can be reversed.

For SLOT B:

fastboot flash init_boot_b init_boot_b.img

Then:

fastboot reboot
