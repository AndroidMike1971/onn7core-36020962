# Root notes

## Verified

- Original successful root work used Magisk 30.7.
- Root path used a Magisk-patched `init_boot_b` image.
- Stock `init_boot_b.img` was preserved before modification.
- A second owner later reported the patched init_boot image working on the same tablet/build.

## Important

Exact flashing commands are intentionally not reconstructed from memory in this file.

Before publishing a step-by-step root procedure, re-verify:

1. active slot behavior
2. exact fastboot/fastbootd context
3. exact target partition name
4. source image hash
5. patched image hash
6. rollback/recovery procedure

Only then promote the procedure from bench notes to user-facing instructions.
